# Desenvolvimento-Front-end

Frontend projects developed during the Web Development course at UCB (Universidade Católica de Brasília).

## Projects

### Site — Dia Nacional da Conservação do Solo
Informational website about Brazil's National Soil Conservation Day (April 15th).
Multi-page layout with navbar, content sections, and cards.

**Pages:** Home, About, Contact
**Tech:** HTML5, CSS3

---

### Site — Dia Mundial da Arte
Informational website about World Art Day, featuring notable artists and Brazilian art history.
Single-page layout with smooth scroll navigation, hero section, artist cards grid, and image content.

**Sections:** About, History, Featured Artists, Art in Brazil
**Tech:** HTML5, CSS3, Google Fonts (Playfair Display + Roboto)
