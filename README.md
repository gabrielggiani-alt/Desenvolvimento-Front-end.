# Front-End Projects

A collection of responsive, hand-coded front-end projects built with **HTML5, CSS3, and vanilla JavaScript** — no frameworks. Each project explores a distinct visual identity, layout system, and set of interactions.

## Projects

### 🍰 Doce Encanto — Artisan Bakery
A 5-page website for an artisan confectionery, with a soft, dreamy visual language.

- Animated gradient background with floating blurred shapes
- Glassmorphism navigation and cards
- Filterable gallery with a custom CSS/JS lightbox (keyboard navigation)
- Static contact form with validation feedback and embedded map
- Fully responsive, mobile-first

**Pages:** Home · About · Menu · Gallery · Contact
**Stack:** HTML5, CSS3 (custom properties, grid, backdrop-filter), Vanilla JS (IntersectionObserver, lightbox, filters)
📁 [`doce-encanto-confeitaria/`](doce-encanto-confeitaria/)

---

### 🥋 World Karate Day
An editorial, Japanese-inspired landing experience celebrating World Karate Day.

- Bold, dark aesthetic with a kanji-driven layout and large display typography
- Animated hero with staggered text reveal and decorative motifs
- Scroll-triggered reveals and a vertical timeline
- Distinct sections for history, styles, belts, and culture

**Pages:** Home · History · Trivia
**Stack:** HTML5, CSS3 (custom properties, grid, keyframe animations), Vanilla JS (IntersectionObserver, mobile nav)
📁 [`dia-mundial-karate/`](dia-mundial-karate/)

---

### 🎨 World Art Day
An informational single-page site featuring notable artists and Brazilian art history.

- Smooth-scroll navigation and hero section
- Artist cards grid with image content

**Stack:** HTML5, CSS3, Google Fonts
📁 [`dia-mundial-arte/`](dia-mundial-arte/)

### 🌱 Soil Conservation Day
A multi-page informational website about Brazil's National Soil Conservation Day.

- Navbar, content sections, and cards

**Pages:** Home · About · Contact
**Stack:** HTML5, CSS3
📁 [`dia-conservacao-solo/`](dia-conservacao-solo/)

## Running locally

Each project is fully static. Clone the repository and open any project's `index.html` in your browser — or serve it with a local dev server (e.g. the VS Code **Live Server** extension) for live reload.

```bash
git clone https://github.com/gabrielggiani-alt/Desenvolvimento-Front-end..git
```

## Tech highlights

- Semantic, accessible HTML
- CSS custom properties for theming and consistent design tokens
- Responsive layouts with CSS Grid and Flexbox
- Scroll-based animations via the IntersectionObserver API
- Zero external CSS/JS frameworks
